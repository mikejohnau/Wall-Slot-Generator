## Full description

Wall Slot Generator takes the geometry out of slot-wall design. Enter three numbers — wall width, height, and border width — and the add-in works out everything else: slot size, spacing, row count, and layout, all proportioned to match a classic, production-proven slot-wall ratio derived from real-world DXF tooling data.

The result is a fully cut solid body, ready for CAM, rendering, or assembly, generated in a single click.

**Two designs built in**

*Design 1 — Rows with inter-row triplets*
Alternating tiers of large stadium slots and smaller [small · large · small] triplets. The inter-row slots sit centred between adjacent main-column pairs, giving the pattern a dense, rhythmic quality suited to display panels, cabinet backs, and acoustic diffusers.

*Design 2 — Brick offset*
Rows of large slots offset by half a pitch on alternate rows, creating a classic running-bond pattern. Optionally adds half-slots — one rounded end, one flat — at the ends of offset rows to fill the space cleanly against the border. Ideal for tool walls, pegboard-style organiser panels, and architectural screening.

**Everything is calculated for you**

There are no spacing fields to fill in. The add-in solves the best slot size and count for your dimensions using a weighted scorer that balances fill efficiency, horizontal/vertical balance, and slot proportions. Change the wall size and the entire layout recomputes. The live SVG preview in the panel updates as you type so you always see exactly what you'll get before generating.

**Non-destructive and re-editable**

Each generation creates a named component. Running the add-in again with new parameters replaces the previous wall automatically — no undo required. The last-used values are saved to the document so the panel reopens exactly where you left it.

**Highlights**
- Live pattern preview — see slot layout, border zone, and slot types before generating
- Auto-calculates slot size, gap, row and column count from wall dimensions
- Supports walls of any size; slots and spacing scale proportionally
- Both designs share the same four-to-one slot aspect ratio and gap ratios
- Half-slots (Design 2) are geometrically correct — proper arc on one end, flat on the other
- Slots centred both horizontally and vertically within the border zone
- Clean component structure — one body, one slot sketch, easy to edit or export
